CSS Animation 학습자료

예제 7-12와 7-13을 합쳐서 배우는 「이동 + 색상 + 테두리 변화」 애니메이션

1. 먼저 알아야 할 핵심

CSS Animation은 시간이 흐르면서 HTML 요소의 CSS 속성을 자동으로 변화시키는 기능입니다.

핵심 공식: animation-name으로 어떤 애니메이션인지 정하고, animation-duration으로 시간을 정한 뒤, @keyframes에서 실제 변화를 설계합니다.
속성쉬운 뜻예제
animation-name실행할 애니메이션의 이름color
animation-duration애니메이션 한 바퀴에 걸리는 시간5s
animation-iteration-count반복 횟수infinite
animation-delay시작 전 기다리는 시간1s
@keyframes시간별 상태를 직접 설계하는 영역0%, 25%, 50%...

2. 두 예제의 관계

예제 7-13: Color Animation

이동하면서 배경색이 바뀌는 애니메이션입니다.

이동 속성: left, top

색상 속성: background-color

예제 7-12: Border Animation

이동하면서 테두리 모양과 두께가 바뀌는 애니메이션입니다.

이동 속성: left, top

테두리 속성: border

중요: 두 예제 모두 @keyframes color라는 이름을 사용하지만, 실제로 무엇을 바꿀지는 keyframes 안에서 결정합니다. 이름이 같아도 속성 내용은 달라질 수 있습니다.

3. 예제 7-13 분석 — 배경색 + 이동

<!DOCTYPE html>
<html>
<head>
  <title>예제7-13 이동 Animation</title>
  <style>
    div {
      width: 100px;
      height: 50px;
      background: cyan;
      position: relative;
      animation-name: color;
      animation-duration: 5s;
      animation-iteration-count: infinite;
      animation-delay: 1s;
    }

    @keyframes color {
      0%   { background-color: red;    left: 0px;   top: 0px; }
      25%  { background-color: green;  left: 200px; top: 0px; }
      50%  { background-color: blue;   left: 200px; top: 200px; }
      75%  { background-color: cyan;   left: 0px;   top: 200px; }
      100% { background-color: orange; left: 0px;   top: 0px; }
    }
  </style>
</head>
<body>
  <div>
    <h4 style="color: gray; margin:0;">iteration Animation</h4>
  </div>
</body>
</html>

5초 애니메이션이므로 약 1.25초마다 다음 keyframe 지점에 도달합니다. infinite 때문에 계속 반복됩니다.

4. 예제 7-12 분석 — 테두리 + 이동

<!DOCTYPE html>
<html>
<head>
  <title>예제7-12 이동 Animation</title>
  <style>
    div {
      width: 100px;
      height: 50px;
      background: cyan;
      position: relative;
      animation-name: color;
      animation-duration: 5s;
    }

    @keyframes color {
      0%   { border: 2px dotted red;    left: 0px;   top: 0px; }
      25%  { border: 5px dashed green;  left: 200px; top: 0px; }
      50%  { border: 15px groove blue;  left: 200px; top: 200px; }
      75%  { border: 5px inset cyan;    left: 0px;   top: 200px; }
      100% { border: 2px solid orange;  left: 0px;   top: 0px; }
    }
  </style>
</head>
<body>
  <div>
    <h4 style="color: gray; margin:0;">translation Animation</h4>
  </div>
</body>
</html>

6. 시험·실습에서 기억할 포인트

① position: relative

left와 top을 사용해 요소를 이동시키려면 위치 관련 설정이 필요합니다.

② 퍼센트는 시간

0%는 시작, 50%는 중간, 100%는 끝입니다.

③ 여러 CSS 속성을 동시에 변경

하나의 keyframe에서 background-color, border, left, top 등을 함께 바꿀 수 있습니다.

④ infinite

애니메이션을 무한 반복합니다. 한 번만 실행하려면 이 속성을 넣지 않거나 반복 횟수를 원하는 숫자로 설정합니다.

학습 순서 추천: 먼저 left/top으로 이동을 이해하고, 그다음 background-color와 border처럼 다른 속성을 keyframes에 추가해 보세요.

7. 직접 수정해 볼 문제

  1. 25% 위치를 left: 300px으로 바꿔 보세요.
  2. 50%의 색상을 purple로 바꿔 보세요.
  3. animation-duration: 5s를 10s로 바꿔 속도 차이를 관찰해 보세요.
